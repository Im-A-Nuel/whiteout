# Whiteout UI kit

Start with `../UI_SPEC.md`. This folder holds the reference material it points to.

- `reference/*.dc.html`  static mockups of the four screens (open in a browser, lift CSS from them)
- `reference/*.png`      screenshots (rendered without web fonts, so text uses a fallback)
- `sprites/*.png`        every sprite at native size, copy to `public/sprites/`
- `art-source/*.py`      generators for the sprites, reference only
